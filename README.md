для диагностики и нейтрализации синтаксических ошибок был выбран метод Айронса. Метод айронса работает таким образом: 
Если текущий токен не соответствует ожидаемому значению или типу, вызывается метод, который регистрирует ошибку. Ошибка записывается в список с указанием фрагмента, позиции и описания, после чего процесс разбора продолжается.

Далее запускается цикл пропуска токенов до тех пор, пока не встретит один из синхронизирующих символов, переданных в массиве, либо пока не будет просмотрено не более 5 токенов. Если синхронизирующий токен найден, метод возвращает `true`; в противном случае — восстанавливает указатель на исходную позицию и возвращает `false`, сигнализируя, что синхронизация не удалась.

Далее другой метод осуществляет поиск одного из необходимых токенов в пределах ближайших 5 токенов. Если нужный токен найден, метод возвращает `true`, что позволяет парсеру продолжить разбор с этого токена.

После синхронизации парсер не возвращается к неудавшемуся правилу — вместо этого переменная  инкрементируется. Если количество ошибок подряд превышает 5, устанавливается флаг, что приводит к аварийному завершению разбора во избежание зацикливания. Родительские методы проверяют флаг после каждого вызова метода регистрации ошибок и прекращают дальнейший разбор при его установке.
